# Embedded Systems Training 

Welcome to my **Embedded Systems Training Repository!**

This repository documents my practical learning journey in embedded systems using ESP32, Arduino IDE, communication protocols, RTOS concepts, sensors, and IoT platforms.

My goal is to develop strong practical knowledge of embedded systems, understand how hardware and software interact, and build real-world embedded applications.

# Learning Objectives

* Understand embedded C programming and microcontroller fundamentals.
* Learn communication protocols such as UART, SPI, and CAN.
* Explore wireless communication using LoRa.
* Implement multitasking using FreeRTOS.
* Interface sensors and actuators with ESP32.
* Develop IoT applications using Blynk and Adafruit IO.
* Understand task execution, inter-task communication, and real-time system behavior.

## Technologies & Tools

* **Microcontroller:** ESP32
* **Programming Language:** C/C++ for Arduino
* **IDE:** Arduino IDE
* **RTOS:** FreeRTOS
* **Communication Protocols:** UART, SPI, CAN
* **Wireless Communication:** LoRa
* **Sensors:** DHT11
* **IoT Platforms:** Blynk IoT, Adafruit IO
* **Components:** RGB LED, buzzer, sensors, and communication modules

##  Projects

### 1. ESP32 CAN Bus Communication Using MCP2515

Exploring CAN bus communication using an ESP32 and the MCP2515 CAN controller.

**Concepts:** CAN protocol, SPI communication, and message transmission.

### 2. ESP32 DHT11 Monitoring with Adafruit IO and Buzzer Control

Monitoring temperature and integrating sensor readings with an IoT dashboard.

**Concepts:** Sensor interfacing, IoT monitoring, and buzzer control.

### 3. ESP32 FreeRTOS Multitasking with Three Tasks and Two Queues

Exploring multitasking and communication between FreeRTOS tasks.

**Concepts:** Tasks, queues, periodic execution, and inter-task communication.

### 4. ESP32 LoRa Wireless Communication Using SPI

Exploring wireless data transmission and reception using LoRa modules.

**Concepts:** LoRa communication, SPI, and wireless data exchange.

### 5. ESP32 Temperature Alert System Using Simulated Temperature

Developing a temperature alert system using simulated temperature values.

**Concepts:** Conditional logic, threshold detection, and alert generation.

### 6. ESP32 UART2 Serial Communication Using Loopback

Learning UART2 serial communication and testing data transmission through a loopback connection.

**Concepts:** UART, baud rate, serial transmission, and data reception.

### 7. ESP32-Based RGB LED Control Using Blynk IoT

Controlling an RGB LED through an IoT dashboard.

**Concepts:** GPIO control, RGB LED interfacing, and IoT-based control.

### 8. Smart Temperature Alert System Using ESP32

Developing a temperature monitoring system that detects threshold violations and generates alerts.

**Concepts:** Temperature sensing, threshold comparison, and embedded control logic.
